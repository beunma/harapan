SELF LEARNING ADAPTIF — 4 DIGIT

Learning hubungan data lama → target berikutnya, multi-level prediction, rolling backtest, penyimpangan, dan adaptive candidate expansion.

1. Masukkan Data RM9

Data harus 4 digit. Data paling kiri = data terlama, data paling kanan = data terbaru. Pemisah boleh koma, Enter, atau spasi.
Jumlah data: 0

2. Pengaturan Learning

SELF-LEARNING NYATA: ranking awal hanya sinyal awal. Pada rolling test, engine menyimpan pengalaman sebelum titik berikutnya: kandidat yang pernah berhasil, wilayah ranking yang ternyata produktif, dan profil digit kuat/sedang/lemah. Sebagian slot kandidat juga sengaja dieksplorasi agar wilayah ranking menengah/bawah tidak mati hanya karena ranking awal salah. Target yang sedang diuji tidak pernah dimasukkan sebelum prediksi selesai.
Perubahan penting: nilai Max Kandidat sekarang bukan sekadar batas atas. Engine akan mengupayakan jumlah kandidat sesuai isian dan melakukan scoring seluruh ruang kandidat. Jika jumlah yang diminta masih berada di dalam ruang kemungkinan (1D=10, 2D=100, 3D=1.000, 4D=10.000), hasil akan diisi sampai jumlah tersebut. Kandidat tambahan tidak dianggap sama kuat: kandidat tetap diurutkan berdasarkan skor gabungan pola, frekuensi, recency, dan hasil backtest.
Minimum sampel pola sekarang benar-benar dipakai. Bila pola sumber belum mencapai minimum sampel, engine tidak membuang pola tersebut, tetapi mengurangi kepercayaan terhadap bukti lokal dan memperbesar pengaruh global/fallback. Jadi nilai 1, 2, 3, dst. memang dapat mengubah hasil scoring.

3. Data yang Dipakai

Data di bawah berasal dari Masukkan Data RM8. Secara default semua data = ON. Matikan selector pada data yang ingin dikeluarkan dari proses learning. Semua perhitungan mesin learning menggunakan DATA YANG DIPAKAI di bawah ini.
Jumlah data dipakai: 0
Catatan: mengubah ON/OFF tidak mengubah data asli di atas. Data yang OFF hanya dikeluarkan dari riwayat yang dikirim ke engine learning.

4. Jalankan Learning

Setelah pengaturan learning dan data ON/OFF selesai, tekan tombol di bawah.

5. Mesin Deret + Toleransi + Voting Kelompok

Mesin ini menguji hubungan antar-posisi data dengan operasi jumlah dan selisih, toleransi -4 sampai +4, validasi historis, lalu voting kandidat. Kelompok tidak dipotong paksa: 2 digit mengambil kelompok utuh sekitar 6–8 unsur, sedangkan 3 digit 7–9 unsur.
